# カジキ釣りゲーム（プロトタイプ）

日本近海のカジキをトローリングで狙うWebゲーム。`spec_01.md` の最小実装です。

## 動かす

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # 型チェック + 本番ビルド (dist/)
```

依存は Vite + TypeScript のみ。描画は Canvas 2D、UIは素のDOM。

## 遊び方

1. **セットアップ画面**でプリセットを選ぶか、船・竿の本数・リール・ライン・ルアーを個別に選ぶ。
   組み合わせの注意点（ドラグがライン強度を超える等）は自動で表示される。
2. **出港**したら、船を動かして潮目（白い点線の帯）や鳥山（鳥が舞う場所）に流す。
   - `← →` / `A D`: 舵　`↑ ↓` / `W S`: スロットル
   - 海面クリック: 目標地点へ自動操船
   - ルアーごとに有効な曳航速度がある（左パネルの「状態」が ◎ なら適正）
   - 生き餌はスロットルを落として潮に乗せる
3. **ヒット**したら他の竿は自動回収され、ファイトに入る。
   - `Space` 長押し: 巻く（魚が走っている間は巻けない）
   - `↑ ↓`: ドラグ調整。安全上限（白いマーカー）を超えると走られた時に切れる
   - テンションが抜けるとフックが外れる。糸を全部出されると終わり
   - ヒット直後は**ファーストラン**。魚が全力で走り、体重に応じて50〜350mほど糸を出される。この間はドラグ音が悲鳴（スクリーム）になる
   - 掛けた直後のドラグはライン強度の約1/3（ストライクドラグ）。走りが止まったら白いマーカー（安全上限）まで締めて巻く
   - 走りには種類がある: **セカンドラン**（最初の休みの後、ほぼ必ず来る強い走り）、通常の走り、**船際の走り**（寄せたところで船を見て走る）、**突っ込み**（深く潜る。糸は出ないが重い）、**船に向かって走る**（糸がふける。巻いて張りを保たないとフックが外れる）
   - **ドラグのクリッカー音**は糸が出る速さに比例。速いとクリックの上に高い唸りが重なる
   - `M` または左上の 🔊 ボタンで音のON/OFF
   - 負けは確率でも起きる: ジャンプで頭を振られてフックが外れる（糸がふけていると3倍、巻いて張っていれば減る）、着水で糸が切れる（テンションが限界近くの時）、限界近くで張り続けて擦れ切れ、船際で口切れ、船に向かって走られた時の糸ふけ
   - ラインブレイク／フックアウト／キャッチの瞬間は数秒の演出が入る（跳ね返る糸、飛んでいくルアー、逃げる魚、大きな表示、効果音）
4. 17:00 の日没で終了。釣果とスコアが表示される。

## 実装されているもの

| 要素 | 内容 |
| --- | --- |
| 船 | 小型ボート / 遊漁船 / スポーツフィッシャー（速度・竿数・沖に出られる限界が違う） |
| 竿 | 1〜5本。多いほどヒット率は上がるが、掛かるのは同時に1本 |
| リール | 30 / 50 / 80 / 130lbクラス（最大ドラグ・糸巻き量・巻き速度） |
| ライン | 30 / 50 / 80 / 130lb（破断強度、太いとヒット率低下） |
| ルアー | スカートルアー / コナヘッド / 弓角 / 生き餌（有効速度・魚種相性） |
| プリセット | 4種（初心者 / ライト / クロカジキ狙い / 生き餌流し） |
| 魚種 | バショウカジキ・マカジキ・クロカジキ・シロカジキ・メカジキ・フウライカジキ |
| 効果音 | Web Audio APIで合成（ドラグクリッカー、巻き音、ジャンプの水しぶき、ラインブレイク、キャッチ）。音声ファイルなし |
| 魚の描画 | 種ごとの体型・配色（吻、背びれの形、縞、腹の白）。水中は上から見た姿、ジャンプ時は横から見た全身に切り替え。尾振りアニメーション |
| 魚の挙動 | 深さの概念（走ると浮上、休むと種に応じて潜る。深いと薄く見え、巻きが重い）、連続ジャンプ、潮目・鳥山付近で水面を切って泳ぐカジキが見える |
| ルアーの挙動 | 船の航跡に沿って追従（曲がると遅れて曲がる）。ルアーごとに引き波が出る。配置は本数で決まる（1本: 中央 / 2本: 左右 / 3本: 左右＋中央ロング / 4本: ショート左右＋ロング左右 / 5本: ＋中央）。`lureLayout` |
| 船の描画 | 船種ごとの形（小型ボート: Tトップ付きセンターコンソール・船外機・イケス / 遊漁船: 操舵室とブリッジ・レーダー・後部デッキのオーニングとイケス・両舷の竿受け / スポーツフィッシャー: コックピットとファイティングチェア・サロン・フライブリッジとハードトップ・ロケットランチャー・タワー・アウトリガーとハリヤード）。キャプテンとアングラーの乗員。竿はバットとティップの2段で、竿受けから出て曳航中は軽く、ヒット中は大きく曲がる。`src/render/boat.ts` |
| 海況 | 潮目3本（ゆっくり移動）、鳥山3つ（出現・移動・消滅）、黒潮による漂流、時間帯による活性 |

## 構成

```
src/
  data/       魚種・装備・プリセットのデータ
  game/       ワールド（潮目・鳥山）、船とヒット判定、ファイトの物理
  audio/      効果音（Web Audio合成）
  render/     Canvas描画（海・潮目・鳥山・船・魚・ミニマップ）
  ui/         セットアップ画面・HUD・結果画面
```

## 調整用メモ

- 魚と船の見た目は `npm run dev` 中に http://localhost:5173/preview.html で拡大して確認できる（`src/preview.ts`）
- 体型・配色は `src/render/fish.ts` の `LOOKS`

- ヒット率: `src/game/sim.ts` の `checkStrikes` 内の係数 `0.005`
- 魚影密度: `src/game/world.ts` の `densityAt`
- ファイトの手応え: `src/game/fight.ts`（引きの力 `0.09`、体力消耗 `0.025`、糸の出方 `0.35`）
- ドラグ音の鳴り方: `src/audio/sound.ts` の `CLICKS_PER_M`（1mあたりのクリック数）、`MAX_CLICK_RATE`、`SCREAM_FROM`（唸りが乗り始める速さ）
- 負けの確率: `src/game/fight.ts` の `jumpShake`（ジャンプでの外れ）、`jumpBreak`、`chafe`、`boatside` の各係数
- 走りの激しさ: `src/game/fight.ts` の `RUN_BOOST`（種類ごとの倍率）、`startRun`（長さ・向き）、`chooseRun`（どの走りが来るかの確率）、糸の出る速さの上限（30 m/s）
- ブラウザのコンソールで `__game` / `__sound` からゲーム状態・音を参照できる
